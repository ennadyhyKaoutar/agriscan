## ❓ Questions Courantes

**Q: Comment ajouter une API réelle?**
A: Voir `app/lib/api.js` et remplacer les données mockées.

**Q: Comment ajouter un modèle TensorFlow.js?**
A: Voir `app/hooks/useDetection.js` et placer le modèle dans `public/model/`.

**Q: Comment déployer?**
A: Suivre DEPLOYMENT.md étape par étape.

**Q: Comment ajouter des traductions?**
A: Éditer `locales/fr.json` et `locales/ar.json`.
